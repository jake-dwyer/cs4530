Performance Comparions of the 3 Matrix Multiplication Implementations:

-- Test Setup -- 
Matrix Size: 10x10
Integers Used: -5 -> 5

-- Results --

1. matrixMultiply | Sequential
  - Runtime: 0.16 ms
  - Fastest by far since all multiplication is done locally with no external networks used.

2. matrixMultiplyAsync1 | Async
  - Runtime: 30,956.00 ms
  - Slowest implementation of the bunch.
  - Each multiplication waits for the remote service before moving onto the next step. The total time adds up linearly alongside the number of operations.

3. matrixMultiplyAsync2 | Async
  - runtime: 4,682.27 ms
  - Among Async1 and Async2, this one is faster because it uses concurrency when calling remote services.
